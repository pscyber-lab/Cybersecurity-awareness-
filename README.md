# Cybersecurity-awareness-
Basic cybersecurity awareness and online safety education by PS cyber
Welcome to the PS Cyber awareness hub.
This project delivers essential guidance on identifying digital threats.
## common threat 
common threat include phishing and malware 
Phishing involves deceptive messages to steal sensitive data.
malware is malicious software designed to damage or gain unauthorized access to systems.
### password best practices 
always use strong, unique passwords.
We recommend using a password manager to keep them organized and enabling two-factor authentication for an extra layer of security.
